# 变更记录

版本号遵循语义化版本。这个项目里三种改动的含义：

- **主版本**：适配包格式或电脑侧 agent 契约发生不兼容变化（别人写好的包会加载失败）
- **次版本**：新增能力、新增命令、新增硬门槛（旧包仍能用，旧 agent 可能不满足新要求）
- **修订**：修 bug、改文档、改提示文案（不影响任何对外契约）

---

## 0.2.0

从"能跑"改成"敢给别人看"。0.1.0 是一个人自己用的脚本，0.2.0 面向的是"别人也会用、别人也会写包"。

### 结构

- 拆成两部分：`engine/`（通用引擎，MIT）与 `game_adapter/`（游戏适配数据）。之前的 `plugin.py` + `adb_bridge.py` 里引擎逻辑与游戏数据混在一起，改一个界面要动协议文件。
- 新增 `game_adapter/base.py`：适配包的加载与校验。校验在加载时做，不等到执行时才发现包有问题。
- 适配包接口三条硬约束：**不含坐标类型**、**`unknown` 是终止条件**、**`config.toml` 里没有坐标块**。
  - 第一条针对"在别人机器上必然失效的绝对坐标"；
  - 第二条针对"认不出来还硬猜"；
  - 第三条是前两条的配置层面对应物——只要配置里能填坐标，前两条就会被绕过。

### 安全门槛（四道门 + 一条强制）

- **免责确认**：`/ship accept`。确认状态持久化到数据目录的 `disclaimer_accepted.json`，与配置项取"或"。为什么不用配置：SDK 的配置写入能力在不同小版本里不统一，指望它会在部分环境静默失败，表现是"我确认过了，重启又让我确认"。
- **校准**：`/ship calibrate`。认不出关键界面就拒绝启用实跑，而不是"尽量试试"。
- **熔断**：连续失败、或出现 `unknown` 界面即停。解除需要显式 `/ship reset`，且解除只表示"允许下一次"，不自动恢复执行。
- **暂停热键强制**：未配置热键时禁止实跑。状态里如实显示"（未验证）"——插件能检查填没填，检查不了那个键在电脑侧是否真的生效。让保护措施看起来完整、实际按下去没反应，比明说"未验证"危险。
- **诊断包脱敏**：`/ship diag` 生成的包里令牌被抹掉、截图只保留结构轮廓。

### 命令

`/ship` 从 6 个子命令扩到 12 个：`help` / `status` / `packs` / `observe` / `run` / `pause` / `resume` / `reset` / `calibrate` / `diag` / `disclaimer` / `accept`。

分工是明确的：`observe` 只读，`run` 可能动手，`status` 解释"为什么被拦"，`diag` 产出发给我看的东西。

### 适配包

- 新增 `demo` 包：4 个界面、3 个只读目标、4 张**手绘线框**模板。线框图不是偷懒——用游戏截图做模板既有版权问题，又会绑死在某个 UI 版本上，还会误导人以为"模板就该长这样"。
- `demo: true` 是**运行时强制**的硬约束，不是标签：demo 包即使四道门全过也只允许演练。改名绕不过去，因为校验在代码里。

### 文档

- `docs/适配包格式.md`：字段定义、三条约束、demo 标准、提交边界。"教学性质"给了三条可检查的判据，不是形容词。
- `docs/电脑侧Agent契约.md`：8 个接口的完整定义，含演练语义、校准规范、诊断包脱敏规则。写给"不想用我这份 agent、想自己写一个"的人。
- `docs/免责声明.md`：风险逐条写清，包括哪些事它不做。
- `docs/项目备忘.md`：已定决策与理由。写它是为了防止半年后被"再优化一下"推翻——推翻通常不是因为想清楚了，是忘了当初为什么。

### 自检

三个脚本，分工不同：

| 脚本 | 项数 | 覆盖 |
| --- | --- | --- |
| `selftest.py` | 50 | 结构约束、演练行为、拦截行为、闸门、免责持久化 |
| `plugin_smoke.py` | 30 | 插件注册、12 个子命令可用性 |
| `e2e_dryrun.py` | 31 | 真 HTTP 假 agent，测协议与链路 |

`e2e_dryrun.py` 的核心断言是"演练全程假 agent 侧输入事件数为 0"。比"返回 ok"有意义：返回 ok 只说明流程走完，零输入事件才说明真的没动。

### 修正

- `manifest` 六处：`author.url` 与 `urls.repository` 原误填文档站地址；补 `license`、`urls.homepage`、`urls.issues`、`i18n.supported_locales`、`sdk`、`host_application`。
- 根目录不再放 `config.toml`，改为 `config.example.toml` + `.gitignore` 排除。
- 鉴权头由契约里的 `Authorization: Bearer` 改为实现实际使用的 `X-Token`，并要求 agent 侧两种都接受。原因很实际：契约和实现不一致，出错时会浪费半天去查一个不存在的问题。

## 0.1.0
